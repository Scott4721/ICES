METHODS OF GARBAGE COLLECTION



Method 1- GC.Collect()

According to (geeksforgeeks.com, 2026), GC.Collect() forcibly collects all generations.



Method 2- GC.GetTotalMemory()

According to (geeksforgeeks.com, 2026), GC.GetTotalMemory() calculates and displays the amount of bytes in managed memory that have been allocated



Method 3- GC.MaxGeneration

According to (geeksforgeeks.com, 2026), GC.MaxGeneration displays the maximum generation that the system supports.



Method 4- GC.GetGeneration(object obj)

According to (geeksforgeeks.com, 2026), GC.GetGeneration(object obj) displays the generation of a given object



Method 5- GC.WaitForPendingFinalizers()

According to (learn.microsoft.com, 2026), GC.WaitForPendingFinalizers() suspends the thread until the thread responsible for emptying the queue of finalizers has finished.
